A hands-on portfolio documenting my journey toward becoming a SOC Analyst. This repository contains practical security investigations, log analysis, network traffic analysis, SIEM exercises, detection engineering, and incident response labs.

## About This Repository

The purpose of this repository is to demonstrate practical cybersecurity skills through documented investigations and reproducible lab exercises.

## Investigation Methodology

My general investigation workflow:

1. Understand the alert or security question.
2. Collect relevant logs and evidence.
3. Filter and correlate events.
4. Investigate suspicious activity and alternative explanations.
5. Assess findings and limitations.
6. Recommend appropriate next steps.
7. Document the investigation and supporting evidence.
